# Security Policy

The AI Recruitment System is committed to candidate data privacy, local data sovereignty, and responsible AI governance.

## Supported Versions

| Version | Supported |
| :--- | :--- |
| 3.x.x | Yes |
| < 3.0 | No |

## Reporting a Vulnerability

If you discover a security vulnerability, please do NOT open a public GitHub issue.

Instead, please report security concerns directly to the project maintainer via:
- GitHub Security Advisories: [Report a vulnerability](https://github.com/shrs425p/AI-Recruitment-System/security/advisories/new)
- Maintainer Profile: [https://github.com/shrs425p](https://github.com/shrs425p)

Please include:
1. Detailed description of the vulnerability.
2. Steps to reproduce the issue.
3. Potential impact on candidate data or system privacy.

For comprehensive details on encryption at rest, CSRF validation, airgap enforcement, and candidate data isolation, see the [Security & Privacy Guide](docs/security.md).
