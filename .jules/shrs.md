## 2026-08-12 - [Switch to Electron Desktop App] **The Problem:** The app was using pywebview for the desktop GUI which has some limitations compared to modern web wrappers like Electron. **The Execution:** We created an Electron frontend (desktop/main.js, desktop/preload.js), updated the frontend UI to use window.electronAPI instead of window.pywebview, updated main.py to securely spawn Electron by passing the port and authentication nonce in environment variables instead of exposing an HTTP endpoint, and replaced the pywebview dependency in requirements.txt. **The Impact:** The desktop app now runs via Electron providing a more mature ecosystem.
