# Contributing to AI Recruitment System

Thank you for your interest in contributing to the AI Recruitment System (ARS).

Please read our detailed [Contributing Guide](docs/contributing.md) for full instructions on:
- Setting up the development environment
- Code conventions and formatting rules
- Running the automated verification tests (`pytest -v`)
- Air-gap and privacy compliance requirements
- Submitting pull requests

## Code of Conduct

All contributors are expected to uphold a professional, respectful, and collaborative environment.

## Submitting Pull Requests

1. Fork the repository and create a feature branch (`git checkout -b feature/your-feature-name`).
2. Ensure all automated tests pass without errors (`pytest -v`).
3. Verify static analysis passes (`ruff check .`).
4. Submit a Pull Request targeting the `main` branch with a clear description of your changes.
